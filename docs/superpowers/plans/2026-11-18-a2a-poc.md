# A2A PoC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a greenfield uv project exposing one LLM-backed chat agent over the A2A protocol (JSON-RPC + SSE) plus a streaming console client.

**Architecture:** A FastAPI app serves A2A routes (agent card at `/.well-known/agent-card.json`) wired through `DefaultRequestHandler` + `InMemoryTaskStore` to a `ChatAgentExecutor` that streams OpenAI-compatible LLM deltas as task status/artifact events. A console client resolves the card and prints the live event stream. All LLM endpoint inputs come from `.env` (`LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`).

**Tech Stack:** Python 3.13, uv (`uv_build`), `a2a-sdk[fastapi]>=1.3`, uvicorn, `openai` (AsyncOpenAI), python-dotenv, pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-11-18-a2a-poc-design.md`

## Global Constraints

- `a2a-sdk[fastapi]>=1.3` — A2A spec 1.0 API. Many online examples are 0.3-era and wrong for 1.x: spec 1.0 uses the unified `Part` model, `SCREAMING_SNAKE_CASE` enums (`TaskState.TASK_STATE_COMPLETED`), `SendMessage`-style operations, `/.well-known/agent-card.json`, and `supported_interfaces` in `AgentCard`. When an import or attribute name in this plan differs from the installed SDK, check `a2a.types` and the official tutorial (a2a-protocol.org/latest/tutorials/python) and use the current equivalent — but never weaken a test's assertion to make it pass.
- Python 3.13; uv project with `src/` layout and the `uv_build` backend; `uv.lock` committed.
- Server binds `127.0.0.1:9999`.
- Env vars: `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`. No credentials in the repo; `.env` never committed.
- `.gitignore` is owner-provided — NEVER create or modify it.
- No code copied from `private-assistant`.
- Every task ends with a commit; conventional commit messages.

## Review Focus

1. Missing `.env` values must fail fast naming every missing var → `tests/test_config.py::test_load_config_missing_vars_fail_fast` (Task 1).
2. An LLM error mid-stream must mark the task FAILED, not hang → `tests/test_executor.py::test_llm_failure_marks_task_failed` (Task 4).
3. CJK text must stream through intact → `tests/test_executor.py::test_executor_streams_cjk_text` (Task 4).
4. Server must serve the agent card without real credentials → `tests/test_server.py::test_agent_card_route_serves_card` (Task 5).
5. Client against an unreachable server must exit with a friendly message, not a traceback → `tests/test_client.py::test_client_dead_server_friendly_error` (Task 6).

**Files:**

- Produces: `ChatAgentExecutor(AgentExecutor)` from `a2a.server.agent_execution`, constructed as `ChatAgentExecutor(agent: ChatAgent)`; `async def execute(context, event_queue) -> None`; `async def cancel(context, event_queue) -> None` (no-op). - [ ] **Step 1: Write the failing test.** `tests/test_executor.py`:

```python
from types import SimpleNamespace

from a2a.helpers import new_text_message
from a2a.types import Role, TaskState

from a2a_poc.executor import ChatAgentExecutor


class FakeAgent:
    def __init__(self, chunks=None, error=None):
        self._chunks = chunks or []
        self._error = error

    async def stream_reply(self, user_text: str):
        for c in self._chunks:
            yield c
        if self._error:
            raise self._error


class FakeEventQueue:
    def __init__(self):
        self.events = []

    async def enqueue_event(self, event):
        self.events.append(event)


def _context(text: str):
    return SimpleNamespace(message=new_text_message(text, role=Role.ROLE_USER), current_task=None)


def _artifact_text(events):
    parts = []
    for e in events:
        artifact = getattr(e, "artifact", None)
        if artifact is not None:
            parts.extend(p.text for p in artifact.parts)
    return "".join(parts)


def _final_state(events):
    states = [e.status.state for e in events if hasattr(e, "status")]
    return states[-1]


async def test_executor_streams_deltas_and_completes():
    queue = FakeEventQueue()
    executor = ChatAgentExecutor(agent=FakeAgent(chunks=["Hel", "lo"]))
    await executor.execute(_context("hi"), queue)
    assert _final_state(queue.events) == TaskState.TASK_STATE_COMPLETED
    assert _artifact_text(queue.events) == "Hello"


async def test_executor_streams_cjk_text():
    queue = FakeEventQueue()
    executor = ChatAgentExecutor(agent=FakeAgent(chunks=["你好", "，A2A"]))
    await executor.execute(_context("用中文打个招呼"), queue)
    assert _final_state(queue.events) == TaskState.TASK_STATE_COMPLETED
    assert _artifact_text(queue.events) == "你好，A2A"


async def test_llm_failure_marks_task_failed():
    queue = FakeEventQueue()
    executor = ChatAgentExecutor(agent=FakeAgent(error=RuntimeError("boom: 401 Unauthorized")))
    await executor.execute(_context("hi"), queue)
    assert _final_state(queue.events) == TaskState.TASK_STATE_FAILED
    assert _artifact_text(queue.events) == ""
```

- [ ] **Step 2: Run to verify it fails.** `uv run pytest tests/test_executor.py -v` — expect import failure.

- [ ] **Step 3: Implement `src/a2a_poc/executor.py`.** Follow the official tutorial's executor pattern: `task = context.current_task or new_task_from_user_message(context.message)` (from `a2a.utils`); enqueue the task only when newly created; build a `TaskUpdater` (from `a2a.server.tasks`) with `task_id=task.id, context_id=task.context_id`; set `TaskState.TASK_STATE_WORKING` first. Then iterate `agent.stream_reply(get_message_text(context.message))` (helper from `a2a.utils.message`): each delta becomes one artifact update whose part text IS the delta, so that concatenating all artifact texts across events equals the full reply (use the TaskUpdater's streaming-artifact mechanism if the installed version provides one — inspect its `add_artifact` signature; otherwise emit an artifact update per delta). On an exception from the stream: `update_status(state=TaskState.TASK_STATE_FAILED, message=new_text_message(f"LLM call failed: {exc}"))` and return. On success: `update_status(state=TaskState.TASK_STATE_COMPLETED)`. `cancel` is a no-op.
